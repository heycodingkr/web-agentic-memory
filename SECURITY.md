# Security policy

Web Agentic Memory is an early-stage design and integration repository. It is not a production service, and there are no supported release versions yet.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository when it is enabled. If it is unavailable, contact the maintainer privately through the GitHub profile associated with this repository. Avoid filing a public issue for an unpatched vulnerability.

Include the affected file or revision, a concise impact description, and reproduction steps using synthetic data. Do not include working API keys, passwords, cookies, private account details, or unpublished website content.

## Data handling

Contributions and examples should contain only synthetic or explicitly public information. Do not commit local browser profiles, generated traces from private accounts, environment files, or credentials.
