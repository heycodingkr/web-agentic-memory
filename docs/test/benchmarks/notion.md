# Notion — remeasurement pending

**No current Notion performance result is published.** The previous candidate runs used memory versions that are no longer considered valid for the intended comparison. Their timings and call counts have been withdrawn from the README, landing page and this report. Do not use those runs to claim that the current Notion memory helps or slows a workflow.

Remeasurement is tracked in the workspace benchmark issue. A corrected comparison must use a version-pinned, task-specific Notion memory and the same task-only prompt in a fresh private QA workspace. Run both conditions with the same host, model, effort, browser tools and starting state; randomize or alternate condition order and repeat each condition at least three times. Independently verify the database, requested rows and properties, table sort, board grouping/filter and saved state. Move only the benchmark's own QA data to Trash after verification.

**Memory revision (2026-11-01).** The Notion memories were remade after a root-cause review. The earlier texts told the agent to inspect, verify, reopen and reload, which adds read-only steps without shortening the interface work. The revised L1 and L2 keep only actions and the facts that prevent detours (a database instead of a simple table, reusing existing properties, page bodies only when requested, the Complete status group including Done, closing the sidebar when view tabs are clipped) and keep optional steps conditional. The revised memory has not been measured, so no speed claim is made for it.

The intended task is to create a private task database with dates and statuses, sort the table, and filter a board to hide completed tasks. A new report will be added only after the corrected memory has been used in a fresh run. Google Docs, Google Slides, Gmail, Figma and Canva examples elsewhere in the repository are not Notion performance substitutes; each needs its own measured task before a speed comparison can be claimed.
